# Arshal Soren — portfolio

A terminal-style portfolio. Plain HTML, CSS, and JavaScript, with no build step.

- `site/` is the published site. Open `site/index.html` in a browser to run it locally.
- `docs/` holds the product brief and decision log. It is not published.
- `.github/workflows/pages.yml` deploys `site/` to GitHub Pages on push to `main`.

Type `help` in the terminal to see the commands.
